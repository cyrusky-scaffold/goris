# Goris

This tool is for create template projects, the project list as folowed:

- [An Empty Node Project](https://github.com/cyrusky-scaffold/templates-node-project.git)
- [An Empty Koa Project](https://github.com/cyrusky-scaffold/templates-empty-koa-project.git)
- [An Empty Deno oka Project](https://github.com/cyrusky-scaffold/templates-deno-oak.git)
- [An Empty VSCode Extension Project](https://github.com/cyrusky-scaffold/templates-vscode-extension.git)

# How to use

```bash
npx goris create
```

## Step 1

name the project

```shell
$ npx goris create
Need to install the following packages:
goris@0.0.11
Ok to proceed? (y)
? Enter the project name (my-project)
```

## Step 2
Set the project path, if you are in the right pwd, you can leave this step to default.

```shell
# npx goris create
Need to install the following packages:
goris@0.0.11
Ok to proceed? (y)
✔ Enter the project name test-project
? Enter the project path (D:\code\test/test-project)
```
